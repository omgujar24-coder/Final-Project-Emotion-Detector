# Simple Python Flask Web Application

A lightweight Python web application built using the Flask framework and structured as a reusable module.

## Description
This project demonstrates Python web development fundamentals, including API routing, handling HTTP methods (GET/POST), package structuring with `__init__.py`, and automated unit testing.

## Features
- Modular package structure
- RESTful routes built with Flask
- Unit testing with Python's built-in `unittest` module
- Static code formatting following PEP 8 standards
